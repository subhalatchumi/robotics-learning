🤖 From Classical to Learning-Based Robotics

📖 About the Project

This project explores the evolution of robotics from classical, model-based approaches to modern learning-based methods. It covers robot kinematics, motion and feedback control, the limitations of traditional robotics, and the role of machine learning in developing adaptable robotic systems.

It also introduces LeRobot, an open-source library for robotics datasets, model training, evaluation, and practical robot-learning experiments.

🎯 Objectives

- Understand the foundations of classical robotics.
- Explore the advantages and limitations of learning-based robotics.
- Learn about robotics datasets and the LeRobot ecosystem.
- Understand Reinforcement Learning, Imitation Learning, and Foundation Models.
- Explore practical robot-learning workflows.

🚀 Suggested Practical Project

Pick-and-Place Robot Using Imitation Learning

The project workflow includes:

- Collecting robot demonstrations
- Preparing camera images, robot states, and action data
- Training a robot policy
- Evaluating the model's performance

Compatible robotic platforms, such as SO-100 or SO-101, can be explored for practical experiments.

📝 Learning Outcomes

After studying this project, learners can:

- Explain the differences between classical and learning-based robotics.
- Understand basic robot movement and control concepts.
- Describe how robotics datasets support model training.
- Explain the fundamentals of reinforcement and imitation learning.
- Identify applications of foundation models in robotics.

🧠 Final Chapter Quiz

The chapter includes a 10-question quiz covering robot motion, forward and inverse kinematics, Jacobians, classical robotics limitations, learning-based robotics, datasets, and behavioral cloning.
